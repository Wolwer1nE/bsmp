# Тестирование от 24.09.2026

Тестировалась сходимость солверов bicgstab и gmres на разных предобуславливателях.

## О данных

Данные - матрицы из наборов BFWAVE, SME3D и CYLSHELL. Для BFWAVE и CYLSHELL брались rhs из задачи.
Для SME3D есть как эксперимент с правой частью из задачи, так и со сгенерированной скриптом (о нём ниже в инструкции по запуску).

## Как запустить

1. В папку data скопировать матрицы из архива
2. (Опционально) сгенерировать правые части скриптецом `gen_rhs.py`. Usage:
```
python gen_rhs.py SIZE OUTPUT_FILE FROM TO
```
Создаёт в OUTPUT_FILE плотный вектор размера SIZE с элементами в диапазоне от FROM до TO
3. Запустить скрипт compare_all.sh. Пример команды, использованный в экспериментах:
```sh
./bin/compare_all.sh --matrix data/bfw782a.mtx --rhs data/bfw782a.rhs
```
Команда сама билдит как нужно. На делле по дефолту подтянулся gcc-release пресет, как кажется.
4. (Альтернатива) Есть написанный на скорую руку скрипт массового запуска 10k_iter_for_all.sh. Запускает compare_all на всех матрицах из папки data. 
Важная деталь: для работы скрипта матрицы и rhs к ним должны иметь одинаковое название и различаться только расширением - mtx или rhs. Именно в силу этой детали
у матриц из SME3D есть дубликаты. Матрицы и rhs с постфиксом \_duplicate являются связкой матрица/rhs, где rhs взят из задачи. Соответственно, там, где этого постфикса
нет, rhs сгенерирован с помощью gen_rhs.py.
